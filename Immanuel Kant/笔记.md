# 先验分析论

**回答问题：**知性（Verstand）是如何使经验成为可能的？

**核心思想：**知性不是被动接受世界，而是主动组织世界。

## **概念分析论**

- 研究：知性有哪些先天概念？

- 回答：知性到底有哪些工具？

- 十二范畴：**范畴就是知性的先天形式**。

  - 康德认为，人并不是先观察大量事物，再从经验中归纳出这些概念；相反，这些概念是知性先天具有的，<u>是经验之所以能够形成的条件</u>。**范畴并不是经验中的内容，而是经验得以成为"有对象、有规律的经验"所必须遵循的思维规则。**

  - 知性的主要功能就是**"作判断"**。人类所有判断，一共有多少基本形式？传统逻辑认为共有十二种。那么它一定具有十二种对应的思维功能。范畴其实就是判断形式在对象上的应用。**每一类范畴中的“第三个范畴”，永远是前两个范畴的结合。**

  - **质量范畴**不是物理里的质量，而是对象具有什么<u>性质</u>。

  - **关系范畴**是整个《纯粹理性批判》中最重要的一组，因为自然科学几乎全部建立在这一组上。

  - **模态范畴**不是说明对象是什么，而是说明对象以什么方式存在。

    - **生成上的“综合关系**
      - **或然（对应“可能性”）**：指一个概念在逻辑上不自相矛盾，符合知性的形式条件。*（它在理论上“可以有”）*
      - **实然（对应“现实性”）**：指一个事物不仅逻辑上可能，而且已经被人类的感官经验所直观捕获。*（它在当下“确实有”）*
      - **必然（对应“必然性”）**：**康德将其定义为“由可能性本身所决定的现实性”。** 也就是说，当一个现实存在的东西（实然），其背后具备了无可逆转的先验法则支撑（例如因果律），导致它**非如此不可**时，它就从单纯的“实然”跨越到了“必然”。
      - **哲学本质**：“必然”不是凭空产生的第三种神秘状态，它本质上就是**被加上了条件约束的“实然”**。

    - **认知关系上的“阶梯递进”**
      - **起点 —— 或然（思维阶段）：** 客体仅仅停留在**纯粹知性**中。你脑海里构想了一个符合逻辑的事物，此时主体对它的态度是“存疑的、备选的”。
      - **中点 —— 实然（感知阶段）：** 客体进入了**经验直观**中。感官把数据交给了你，事实摆在眼前，此时主体的认知态度变成了“确定其存在”。
      - **终点 —— 必然（法则阶段）：** 客体被纳入了**普遍法则的连接**中。你不仅看到它存在，还通过理性推导出了“它之所以存在的充分必要条件”，此时主体的认知态度变成了“不可更改的强制性确认”。

## 原理分析论

- **研究内容：**如何把这些工具（范畴）正确地应用到感性经验中去，从而说明自然科学的普遍必然规律是如何可能的。
- **纯粹知性概念的图形论**：纯粹的知性概念（如因果性）是完全抽象的，而感性经验（如看到的烟和火）是具体、形象的，这两者怎么结合？
  - **解决方案**：引入“先验图型”作为中介。
  - **核心媒介**：**时间**。时间既具有感性的直观形式，又具有知性的普遍规律性。知性范畴通过在时间中打上烙印，变成了能够应用于现象的“图型”（例如：“因果性”的图型就是“时间上规律性的前后相继”）。

- **纯粹知性原理体系**：这是原理分析论的**主体**。康德在这里推导出了构成人类知识客观必然性的四类原理，直接为牛顿力学和自然科学奠定了形而上学基础

| **原理分类**           | **核心内涵**                                                 | 对应物理/自然科学规律                                        |
| :--------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **直观公理**           | 一切现象在直观中都是“量”；必须服从空间与时间的“连续量”；经验对象在形式上是可数学化的（广延量）。 | 只要进入我们视野的现象，都必须服从**数学和几何学**。         |
| **知觉预期**           | 现象中作为感觉对象的实在都具有内含的量（程度/强弱）。感觉不是离散的，而是连续强度的变化。 | 经验世界中的光、热、重力等物理现象都是**连续可测量的**（没有绝对的虚空）。 |
| **经验类比**           | 经验的连接必须通过现象间必然连接的表象。自然界的“规律性”不是从经验归纳来的，而是知性先天规定的。 | **实体常住性**（物质守恒）；**因果律**（时间里的相继服从因果）；**协同性**（空间里同时存在的事物相互作用） |
| **一般经验思维的公设** | 界定什么是经验上的**可能、现实与必然**。可能性：符合形式条件即可；现实性：必须与感觉相符；必然性：必须符合普遍规律（因果系统）；经验对象的“存在方式”受认识条件限制。 | 必须符合感性与知性条件的才是可能的；与感觉相连的是现实的；与现实通过因果相连的是必然的。 |

- **现象与物自体的界限**：康德在最后划定了一条不可逾越的红线：
  - **现象：通过时空和范畴建构起来的、我们可以认识的世界。
  - **物自体**：独立于人类主观认知结构之外的客观实在。
  - 知识的有效范围 = 经验可能范围

- **最终结论**：知性为自然立法，但知性的普遍必然原理只对“现象”有效，对“物自身”无效。经验世界之所以具有数学性与规律性，不是因为世界本身如此，而是因为人的知性通过范畴与图型结构“规定”了经验世界的可能性。
  -  **认识是“先天结构 + 感性材料”的综合**：感性提供“杂多”；知性提供“形式”；图型完成连接；经验不是被动接受，而是被结构化建构的。
  - **自然科学的合法性**：空间、时间以及因果律等并非客观世界本身具有的属性，而是人类知性强加给经验的。因此，自然科学（如牛顿力学）之所以具有放之四海而皆准的普遍必然性，是因为**我们只有通过这些规律才能体验和建构出一个“自然界”**。
  - **形而上学的限界**：知识的边界就是经验的边界。一旦我们的理性试图脱离感性经验，把因果律等原理拿到“物自身”（如上帝、灵魂、世界整体）上去应用，就会陷入无法解决的逻辑混乱。
  - **为信仰留出地盘**：既然科学（理性）只能认识现象，无法触及本体（物自身），那么关于上帝、自由和灵魂不朽等形而上学问题就无法在科学中被证实或证伪。这成功地将“知识”限制在科学经验领域，而将形而上学引向了“实践理性”（道德与信仰）领域。
